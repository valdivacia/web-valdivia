# Web de Valdivia & Cía. Estudio Jurídico

Sitio estático (HTML y CSS, sin dependencias). Se publica con Netlify o Cloudflare Pages directamente desde la rama `main`.

- `index.html`: página principal
- `gracias.html`: confirmación después de enviar el formulario de contacto (Netlify Forms)
- `favicon.svg`: monograma VC

Colores: azul marino #1F2D4A, gris acero #6B7380, gris perla #C9CDD3, gris azulado #A9B4C6, blanco humo #F3F4F6. Tipografías: Marcellus (títulos) y Jost (textos).

Formulario de contacto: Netlify Forms (detección de formularios activada el 15-10-2026). Notificaciones en Netlify > Forms > Form submission notifications.
